# Some Wayland Example Programs

```sh
cargo run --bin niri-crash                          # wayland client that crashes niri
cargo run --bin window-with-tags                    # window that sets xdg toplevel tags (before the first commit)
cargo run --bin window-with-tags-after-configure    # window that sets xdg toplevel tags (after the first configure)
cargo run --bin black-bars                          # layer shell adding black bars to the left and right
```
